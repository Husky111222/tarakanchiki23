Данная игра называется "Тараканьи бега"
Цель игры заключается в пересечении финиша одним тараканом, быстрее другого
Финиш - конец поля, на котором находятся тараканы
<img width="802" height="437" alt="image" src="https://github.com/user-attachments/assets/98b844c8-efbb-4e9e-a374-ca4723cbb63c" />
Игроки вводят свои имена в верхние поля, для верхнего таракана левое поле, для нижнего правое
<img width="800" height="442" alt="image" src="https://github.com/user-attachments/assets/b9e06a31-0b4f-477a-804d-87b0ee127776" />
После того как игроки введут имена, необходимо нажать на кнопку "СТАРТ", игра начнется.
<img width="798" height="477" alt="image" src="https://github.com/user-attachments/assets/cdd7fbb8-7479-44a7-9174-35177c9eb0a7" />
Побеждает таракан, который быстрее достигнет финиша, сообщение о победе игрока появится справа от имен игроков
<img width="806" height="482" alt="image" src="https://github.com/user-attachments/assets/7747bf7a-0b79-4a7b-ab75-8e1ba57b1e80" />
Для начала второго и последующего раунда необходимо нажать на кнопку "Сброс". Тараканы вернутся в изначальное положение
<img width="803" height="441" alt="image" src="https://github.com/user-attachments/assets/78eba33f-7d51-4de6-8f02-94977332150c" />
Если один из игроков не введет имя, появится ошибка
<img width="179" height="149" alt="image" src="https://github.com/user-attachments/assets/e0742277-c7fa-4f88-aa3b-be0864b202b4" />
